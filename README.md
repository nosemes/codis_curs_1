# Laboratori Raspberry Pi · Biblioteca de codis

Web estàtica per a GitHub Pages.

## Publicació

1. Puja el contingut d’aquesta carpeta a l’arrel del repositori GitHub.
2. A Settings → Pages, selecciona Deploy from a branch, branca main, carpeta / (root).
3. Desa i espera la publicació.

## Fidelitat dels codis

Els `.py` mantenen el contingut original, amb una única excepció: els tokens reals de Telegram s’han substituït per un token fictici no funcional. No s’han corregit altres errors ni reformatat els fitxers.

**Seguretat:** revoca el token original amb BotFather abans de publicar.
